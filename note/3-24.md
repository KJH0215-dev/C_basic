##  오늘 공부한 내용 (3-24)

### 연산자와 피연산자
- 예시
- sizeof(int) --> sizeof: 연산자, int: 피연산자 
- a = 10 --> '=': 연산자, 'a', 10: 피연산자

- 연산자의 갯수에 따라 단항/이항/'삼항'(애는 수학에 없는 형태)
- 삼항 연산자 사례: x ? y :z

### 연산자의 종류
- &(2nd warming up pdf 4장 참고)

### 산술 연산자
- +, -, *(곱하기), /(나누기)
- <주의>: 나누기를 할 때 주어진 숫자 모두 정수인 경우 하나를 double형으로 바꾸지 않으면 몫만 출력되기 때문에 형변환을 해줘야함 
- 예시: int a=2, b=1;   b/a --> 그냥 0이 출력됨. 왜? 그야 정수만 보니까 소수점을 버림
- 올바른 표현: (double)b/a, 
- but (double)(b/a) 이렇게 하면 안됨 왜? 괄호를 먼저 인식하기 때문에 정수 상태로 한번 나누고 double 형변환이 이루어짐

### 피연산자의 형변환
-  피연산자의 데이터형이 서로 다르면 피연산자를 같은 형으로 형변환 한 다음 연산을 수행함


### 증감 연산자
- 변수의 값을 +/-1씩 시키는 연산자
- 변수에만 사용 가능 / 상수, 수식에는 사용 불가
- (+): ++/--의 형태에 한해서 전위와 후위 연산이 가능
- 전위형: a++ = a값을 한번 인출하고 다음 값에 +1 / 후위형: ++a = a에 +1을 한다음 인출

### 관계 연산자
- 두 수의 값을 비교하기 위한 연산자
- 관계 연산식의 값은 항상 참(1) 또는 거짓(0)이 된다.
- 관계 연산식은 if문, for문, while문등의 조건식으로 주로 사용된다.
- <주의>: 90 <= a <= 100을 표현 할때 C에서는 아래와 같이 적어야 문제가 안생김
- 90 <= a && a <= 100
- 왜? 이렇게 안하면 순서에서 꼬여서 90 <= a 를 먼저 판단하여 0, 1을 출력하는데 0, 1은 모두 100보다 작아서 무조건 참인 값이 나오게 됨
- 컴퓨터 문법에서는 '='기호가 대입으로 이미 만들어져서 같다를 표현하려면 '=='형태로 사용해야한다.
