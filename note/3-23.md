### 이스케이프 시퀀스
- \n: 줄 바꿈('C에선 중요')
- \t: 탭
- \\: 역슬래시 출력
- \": " 출력
- \0: 문자열 끝

### 실수의 2진 표현
- 솔직히 모르겠음
- 실수 데이터 형에는 signed/unsigned사용 불가

### float과 double의 정밀도 차이
- float = 4byte -> 정밀도 / 소수점 6자리
- double = 8byte -> 정밀도 / 소수점 15자리
- 훨씬 저장 가능한 값이 많아 이제 수업 중에는 float 사용하지 말라 하셨음

### 실수형의 유효 범위
- float = 표현 범위 작음(10^-38 ~ 10^38)
- double = 표현 범위 큼(10^-308 ~ 10^308)

### 변수의 선언
- int a; 
- ==> 변수의 선언 (= 메모리 확보)

### 변수의 이름
- 변수 지정에서 지켜야 하는 규칙 

- '-'기호 사용 불가
- 빈칸 허용X
- 이름을 숫자로 시작 불가
- 키워드

### 변수의 초기화 
- 형식
- 데이터형 변수명 = 초기값

- 변수의 데이터형과 초기값의 데이터 형이 일치하지 않으면 데이터 형에 맞춰서 값을 변환해서 초기화한다.
- if 변수의 초기화를 사용안하면 컴파일 에러 발생

### 상수 
- 프로그램에서 변하지 않는 수
- 임시값: ?
- 상수의 종류: 1. 리터럴 상수 2. 기호 상수

### 리터럴 상수
- &이건 pdf의 표를 참고하자(2nd warming up 3장)

### 매크로 상수
- #define으로 정의되는 상수
- 전처리 과정에서 #include<'stdio.h'>와 함께 사라지면서 매크로 상수를 특정 값으로 대체한다. 
- <주의>: 매크로 상수에는 ';'을 붙이지 않는다 / 이미 지정된 매크로 상수에는 대입이 불가능하다. 
- (+): 개발자들 사이에서 매크로 상수는 대문자로 쓰는게 관례라고 한다.

### const 변수
- 절대 변경할 수 없는 변수 
- if const 변수 값 변경 시 컴파일 에러 발생
- const함수는 선언 시 초기화를 하는 것이 좋다. (안 그러면 buf_size값에 저장이 불가능)
