# C언어 공부


##  오늘 공부한 내용 (3-19)

### 2진수 - 8진수 - 16진수
- 2진수 (binary): 0,1 → 컴퓨터 내부 표현
- 8진수 (octal): 0~7 → 2진수 3비트씩 묶음
- 16진수 (hex): 0~9, A~F → 2진수 4비트씩 묶음

- 변환 핵심
- 2진수 → 8진수: 3비트씩 끊기
- 2진수 → 16진수: 4비트씩 끊기 

- < ai의 예시파트 >
- 110101₂
- → 110 101 → 65₈
- → 0011 0101 → 35₁₆

### C의 데이터형
- char - 1byte - 문자
- int - 4byte - 정수
- float - 4byte - 실수
- double - 8byte - 정밀한 실수

- sizeof(데이터형)-->메모리 크기 확인

### 3bit 정수표현
- unsigned: 부호가 필요가 없음 --> 모든 데이터를 숫자로 사용 (0~7까지 표현)
- signed: 부호 지정을 위해 1bit 사용함(-4~3까지 표현), 단 음수 표현할 때 2의 보수법이 사용됨.

### 2의 보수법
- 컴퓨터는 멍청해서 덧셈만 할 줄 아는데 뺄셈을 하고 싶은 우리 인간이 뺄셈 하는 법을 가르친다고 생각하면 편한 것 같음
- 순서 1번 비트 반전 -> 2번 +1 해주기

- 예시: +3을 -3으로 바꾸는 법 
- 1: +3을 표현 하면 0011임
- 2: 반전 시키기 --> 1100
- 3: 거기다가 +1 --> 1101
- 결과 = -3(1101)

- 3-2란 식을 3 + (-2)로 바꿔서 컴퓨터가 알아먹도록 바꿔줌

### 오버플로우 
- 지정된 숫자의 범위를 넘어서면 숫자가 이상하게 변함 
- 예시(unsigned): 7+1 --> (111) + (001) = (000) ====> 엉뚱한 0이 나옴

### 아스키코드
- 문자 = 숫자에 매칭 시킨 것 
- 'A' = 65(아스키코드)
- 'a' = 97(아스키코드)

- 그냥 문자를 컴퓨터의 언어로 표현한 것이라 생각하면 편할 것 같다.
